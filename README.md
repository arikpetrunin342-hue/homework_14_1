## Описание проекта

Каталог, созданный в рамках учебного проекта.

## Функционал

В данном продуктовом каталоге содержится файл `class_for_work.py`, в котором присутствуют два класса: `Product` (продукт) и `Category` (категория).
Категории могут содержать список продуктов, а также хранить информацию о количестве категорий и товаров во всём каталоге.

## Тестирование

Проект покрыт модульными тестами. Они проверяют каждую функцию отдельно.

**Что здесь тестируется:**

* Проверка инициализации объектов с передачей параметров (имя, описание, цена, количество — для товара; название категории, её описание и список продуктов — для категории).
* Проверка типа возвращаемого значения фикстур (`isinstance()`).
* Сравнение значений полей созданных объектов с ожидаемыми данными.
* **Проверка метода добавления:** тестируется возможность добавления новых продуктов в категорию через метод `.add_product()`. Проверяется тип возвращаемого значения и то, что продукт действительно добавляется в список.
* **Строковое представление:** тесты проверяют, как объект Category преобразуется в строку методом `__str__()`. Убедиться важно не только в наличии имени и описания, но и в правильном выводе списка всех товаров из этой категории.
* **Пустая категория:** отдельный тест проверяет поведение объекта Category без добавленных товаров. Метод `.products()` должен вернуть пустую строку или сообщение об отсутствии товаров, а строковое представление — содержать только имя и описание.

## Классы

### Класс `Product`
* **Атрибуты:** название продукта (`name`), описание (`description`), цена (`price`), количество (`quality`).
* **Типы данных:** строка, строка, число с плавающей точкой, целое число.

Пример создания продукта:

`product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)`

### Класс `Category`

* **Атрибуты:** название категории (`name`), её описание (`description`), список продуктов (`products`)
* **Типы данных:** строка, строка, список
* **Логика:** при создании новой категории автоматически увеличивается общий счетчик категорий; при передаче списка продуктов обновляется счетчик общего числа товаров.

#### Методы:
*   **`.get_products()`**: публичное свойство, которое возвращает копию внутреннего списка товаров. Возвращает список экземпляров класса `Product`.
*   **`.add_product(product)`**: добавляет новый товар в категорию. Принимает аргумент типа `Product`. Если передан другой тип, возбуждает исключение `TypeError`.

Пример создания категории:

`category1 = Category("Смартфоны",
                         "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
                         [product1, product2, product3])`
