## Описание проекта

Продуктовый каталог, созданный в рамках учебного проекта.

## Функционал

В данном продуктовом каталоге содержится файл `class_for_work.py`, в котором присутствуют два класса: `Product` (продукт) и `Category` (категория).
Категории могут содержать список продуктов, а также хранить информацию о количестве категорий и товаров во всём каталоге.

## Тестирование

Проект покрыт модульными тестами. Они проверяют каждую функцию отдельно.

**Что здесь тестируется:**

* Проверка инициализации объектов с передачей параметров (имя, описание, цена, количество — для товара; название категории, её описание и список продуктов — для категории).
* Проверка типа возвращаемого значения фикстур (`isinstance()`).
* Сравнение значений полей созданных объектов с ожидаемыми данными.

## Классы

### Класс `Product`
* **Атрибуты:** название продукта (`name`), описание (`description`), цена (`price`), количество (`quantity`).
* **Типы данных:** строка, строка, число с плавающей точкой, целое число.

Пример создания продукта:

`tomato = Product(name='tomato', description='red', price=15.50, quanity=10)`

### Класс `Category`
* **Атрибуты:** название категории (`name`), её описание (`description`), список продуктов (`products`)
* **Типы данных:** строка, строка, список
* **Логика:** при создании новой категории автоматически увеличивается общий счетчик категорий; при передаче списка продуктов обновляется счетчик общего числа товаров.

Пример создания категории:

`salad_category = Category(name='for salad', description='good salad', products=['tomato', 'cucumber', 'salt', 'onion', 'sour cream'])`
